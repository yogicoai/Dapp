01

지금까지 완성한 것

앱의 핵심 — “이야기를 만들어 목소리로 들려준다”는 이미 작동합니다.

  • 완료
    이야기 생성 엔진 (앱의 심장)

    세 가지 방식 — 오늘 있었던 일 / 상상 이야기 / 감정 동화. 나이(3~8세)별로 글 수준이 자동으로 달라지고, 장면 수(3~8장)를 고르면 장면별 줄거리 → 본문으로 만들어집니다. 친구·형제는 이름을 넣으면 그대로 등장합니다.

  • 완료
    음성 낭독

    진짜 성우 10명(감정 연기), 캐릭터별 목소리, 읽기 속도 조절. 엄마·아빠 목소리 녹음 자리 마련.

  • 완료
    기본 콘텐츠 — 전래동화 · 세계명작

    빈 책장이 허전하지 않도록 제공하는 서가. 삽화·나레이션·캐릭터 음성 완비.

  • 완료
    테마(나라) 7종 · 그림책나라 신규

    우주·동화·공룡·자동차·공주·바다에 더해, 이사님 컨셉을 그림책나라 테마로 추가(배경·마스코트 여우 “토리”·전용 표지 틀·배경 영상 완비).

  • 완료
    책 뷰어 · 만들기 화면

    페이지 넘김·자동 낭독·클릭 반짝임·배경음, 그림 속 캐릭터 클릭 시 대사. 만들기 위저드·스티커 아이콘 정비.

02

남은 작업 (상용화까지)

  • 필요
    회원가입 · 데이터 저장 (Supabase)

    아이 정보·만든 동화를 계정에 저장. 현재는 기기에만 임시 저장.

  • 필요
    아이 사진 → 주인공 얼굴 반영

    업로드 사진을 삽화 주인공에 반영. 개인정보라 안전한 전용 저장소 필요.

  • 필요
    삽화 생성 정식 가동

    지금은 테스트 비용을 아끼려 글만 생성. 스위치 하나로 삽화가 켜집니다(그림 AI 결제 필요).

  • 필요
    결제 · 크레딧 시스템 (수익 모델)

    1권당 얼마·무료 몇 권. 오늘 회의의 핵심.

  • 필요
    배포 · 이미지 호스팅 연결

    앱은 Vercel + 회사 도메인. 전래·세계명작 같은 고정 이미지·음성은 카페24 이미지 호스팅, 사용자 사진은 전용 저장소.
