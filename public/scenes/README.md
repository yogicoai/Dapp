# 동화 배경 아트 (프론트엔드용)

힉스필드(nano_banana_pro)로 생성한 화면 배경. **전부 하나의 톤** —
따뜻한 수채화, 밤의 다락방, 반딧불이·별·램프 불빛 — 으로 통일해 앱 전체가
한 권의 동화책처럼 보이게 했다.

- 규격: **4:3 가로, 1200×896** (태블릿 전체화면 기준)
- **글자는 굽지 않았다.** 배경 위에 실제 HTML 텍스트를 얹는다 (선명함 + 다국어 + 자유 배치).
- 각 이미지에는 텍스트·버튼이 들어갈 **여백을 일부러 남겼다** (아래 표의 "빈자리").

| 파일 | 화면 | 빈자리 (텍스트·UI 얹을 곳) |
|---|---|---|
| `01-entrance.png` | 입장/시작 | 오른쪽 벽면 → 제목 + "시작하기" 버튼 |
| `02-child-info.png` | 아이 정보 입력 | 가운데 밝은 구름 영역 → 이름·나이 입력칸 |
| `03-theme.png` | 주제 고르기 | 아래쪽 이끼 공터 → 주제 카드(공룡·우주·바다…) |
| `04-outline.png` | 줄거리 확인 | 오른쪽 밤하늘 → 줄거리 4줄 + "이대로 갈까요?" |
| `05-creating.png` | 생성 중(로딩) | 가운데 → "동화를 짓는 중…" (스피너 대신 이 화면) |
| `06-library.png` | 서재(내 동화) | 책장 위 → 만든 동화 커버 썸네일. 위아래 크림 여백은 크롭 |

## 참고

- 실제 **동화 페이지 삽화**는 이 배경들과 다르다. 런타임에 Gemini(같은
  nano_banana 계열)로 장면마다 새로 생성한다. 여기 배경은 앱 UI(껍데기)용.
- 나중에 용량 줄이려면 webp로 변환 (각 ~2.5MB → ~300KB).
- 대안 시안이 필요하면 힉스필드로 재생성 (1장 2 크레딧).
